# 문찬희 자기소개 사이트

백엔드 · AX 개발자 문찬희의 한 페이지 자기소개입니다. https://hwangslater.github.io

- 빌드 없는 정적 HTML·CSS·JS. GitHub Pages 가 저장소 맨 위를 그대로 보여 준다.
- 디자인은 직접 만든 [ui-design-director](https://github.com/HwangSlater/ui-design-director) 스킬로 정했다 — 뼈대 비교 → 색 비교 → 배치 시안 → 완성 시안. 결정과 까닭은 [DESIGN.md](DESIGN.md), 페이지 계획은 [SITE-PLAN.md](SITE-PLAN.md).
- 값(색·글자·간격·움직임)은 `tokens.css`, 부품은 `components.css`, 움직임과 탭 따라가기는 `site.js`.
